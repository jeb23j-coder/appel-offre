Points d'accès

Chaque adresse renvoie un fichier JSON : { source, miseAJour, nombre, donnees: [...] }.

AdresseContenu
v1/index.jsonDescription, licence, compteurs et date de mise à jour.
v1/avis-ouverts.jsonAppels d'offres en cours, du plus urgent au moins urgent : titre, organisme, ville, date limite officielle, addendas, lien SEAO.
v1/contrats.jsonRésultats : chaque soumissionnaire et son prix (du plus bas au plus haut) et l'entreprise retenue avec le montant. Inclut les appels sur invitation.
v1/entreprises.jsonPar entreprise : soumissions, contrats gagnés, montant gagné, taux de succès, soumission médiane.
v1/organismes.jsonPar donneur d'ouvrage : avis publiés, nombre moyen de soumissionnaires, villes.

Exemple

const r = await fetch("https://jeb23j-coder.github.io/appel-offre/api/v1/contrats.json");
const { donnees } = await r.json();
const briques = donnees.filter((c) => /brique|maçonnerie|façade/i.test(c.titre));
console.log(briques[0].soumissions); // [{ entreprise, montant }, ...]

Source : Système électronique d'appel d'offres (SEAO), Secrétariat du Conseil du trésor du Québec, via Données Québec, licence CC-BY 4.0. Données traitées par Radar Chantier.

SEAO publie ces fichiers chaque semaine, avec quelques jours de décalage. Pour les tout nouveaux avis, Radar Chantier utilise aussi son balayage quotidien. La date limite affichée est toujours la date officielle de SEAO.
